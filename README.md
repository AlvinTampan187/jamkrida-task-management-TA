# Jamkrida Task Management

Aplikasi Web untuk Manajemen Tugas dan Monitoring Kinerja Karyawan  
PT. Jamkrida Kaltim

## Deskripsi
Aplikasi ini dikembangkan sebagai Tugas Akhir untuk membantu proses penugasan, monitoring progres, dan evaluasi kinerja karyawan secara terstruktur.

## Fitur Utama
- Manajemen tugas oleh atasan
- Monitoring progres tugas karyawan
- Persetujuan penyelesaian tugas
- Dashboard kinerja karyawan

## Teknologi
- Laravel (Backend)
- Vue.js (Frontend)
- MariaDB (Database)
